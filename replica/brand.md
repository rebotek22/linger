# Zerospace brand

Zerospace is a rebrand of the open-source Linger (SimplexAI) personal agent.
The name was chosen by the owner; this file records the identity and what the
rebrand did and did not change.

## Palette

Graphite and paper, chosen with the unslop skill: untinted neutrals and ink,
matching the flat black logo tile. The chrome has no hue of its own.

| role       | value                        | notes                                   |
| ---------- | ---------------------------- | --------------------------------------- |
| ink        | `hsl(0 0% 7%)` `#111111`     | text, primary buttons, focus, selection |
| muted text | `hsl(0 0% 42%)`              | 5.6:1 on white                          |
| canvas     | `hsl(60 9% 98%)`             | warm paper white                        |
| hairline   | ink at 8%                    | borders                                 |
| live       | `hsl(145 54% 40%)` `#2F9E5B` | only for the live or now dot            |
| logo tile  | `#111111`                    | flat black, white mark                  |

The signature is the logo's satellite dot: a small solid green dot that marks
what Zerospace is working on right now, and nothing else. The login page's one
rich moment is the agent's day as a paper card.

## Logo

- Idea: a zero drawn as an orbit around a Z, with a satellite in the opening:
  your own space, where the agent works and nothing leaves.
- Mark type: symbol plus wordmark (Inter Display SemiBold, outlined).
- Works at 16 px (favicon, tray template) and as a 1024 px app icon.
- Sources: `apps/assets/logo/source/`; every size is generated by
  `apps/assets/logo/export.py`.
- Shares no shape, colour pair or letterform with Linger's ivory L and amber
  dot on a dark tile.

## Voice

Quiet, exact, private.

- Quiet, not cold. Exact, not terse. Private, not secretive.
- No exclamation marks, no trailing periods on short strings, no hype.

## What was renamed

User-facing text and assets: web app (titles, messages, both locales, login,
footer, favicons, wordmark), desktop app (window titles, tray, dialogs, setup
and offline pages, setup errors), Windows installer display strings, macOS
bundle display name, product name in all packages, README and NOTICE.

## What still says Linger, on purpose

`python3 sweep.py . --config replica/brand.json` still reports about 9,000
hits. Nearly all are internal identifiers that installed copies, servers and
upgrades depend on, so renaming them is a separate, breaking migration:

- package names (`@linger/*`), Go module paths, the `linger-installer` app;
- environment variables (`LINGER_*`), data folders (`~/.linger`,
  `AppData/Roaming/Linger`, `Application Support/Linger`), install folders,
  executable and bundle names (`Linger.exe`, `Linger.app`), bundle IDs,
  registry keys, update feed and release file names;
- built-in Skills under `skills/builtin/` (immutable per version);
- upstream docs links (docs.heylinger.com) in README;
- LICENSE and the upstream attribution in NOTICE and README, which must stay.
